# API Testing Project 🔗

## Project Overview
This repository contains API testing project focused on validating RESTful APIs
using structured test cases and Postman collections.

The project covers testing core API functionalities including request validation,
response verification, and basic error handling.

---

## My Role
As a QA Engineer (Trainee), my responsibilities included:
- Designing API test cases
- Executing API requests using Postman
- Validating response status codes and payloads
- Documenting test results
- Preparing test execution and summary documentation

- API Testing
